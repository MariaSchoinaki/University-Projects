# Assignment 2 — Algorithmic Game Theory

This repository contains the report **`report_2.pdf`**, which provides complete solutions to **Assignment 2** for the course:

> **Algorithmic Game Theory — MSc. Computer Science, AUEB (2025–2026)**

The assignment focuses on advanced topics in **algorithmic mechanism design**, **social choice theory**, **matching markets**, **auction theory**, and **efficiency analysis of equilibria**. The solutions include formal proofs, equilibrium computations, and welfare analysis.

---

## Topics Covered

### Problem 1 — VCG Mechanisms

Analysis of a multi-unit auction with identical goods and submodular valuations:

* Enumeration of feasible allocations
* Social welfare maximization
* VCG allocation rule
* VCG payment computation
* Utility calculation for each participant

---

### Problem 2 — Truthful Mechanism Design

Investigation of a path-auction mechanism that selects the path with maximum total cost:

* Incentive compatibility
* Weak Monotonicity (WMON)
* Truthfulness impossibility results
* Mechanism design lower bounds

---

### Problem 3 — Facility Location Mechanisms

Study of strategyproof social choice functions on the interval [0,1]:

* Single-peaked preferences
* Strategyproofness
* Onto social choice functions
* Unanimity
* Formal equivalence proof

### Problem 4 — Stable Matching

Construction of a stable matching instance that maximizes the number of Gale–Shapley iterations:

* Stable Matching problem

* Worst-case execution analysis
* Proposal complexity
